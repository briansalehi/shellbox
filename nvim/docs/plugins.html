overseer.nvim toggleterm.nvimplugins/cmake.lua

Task runner and terminal that cmake-tools drives for its build and run panels. No keymaps of their own.

Load order matters in one place. plugins.cmake must be required before plugins.dap: cmake-tools calls register_dap_function() before nvim-dap exists, so the dap module re-runs it.

vim-illuminateplugins/editor.lua

Faintly highlights other occurrences of the symbol under the cursor once it rests. Providers are lsp then regex — the treesitter provider needs nvim-treesitter.locals, absent from the main-branch rewrite, so C++ resolves through clangd and everything else by word match.

A-n · A-p
Next / previous occurrence
A-i
Select an occurrence as a text object

:IlluminateDebug names the provider it picked for the current buffer.

nvim-treesittermain branch · plugins/treesitter.lua

Parsers for c, cpp, lua, cmake, python and rust, started per filetype. This is the main rewrite, not master: modules like nvim-treesitter.locals and .query do not exist, which rules out plugins that depend on them.

Requires the tree-sitter CLI on the machine. Without it the install fails silently on every launch and the parser directory stays empty.

nvim-treesitter-contextplugins/treesitter.lua

Pins the enclosing function and loop to the top of the window while scrolling. Capped at 3 lines and disabled under 20 rows, because the default is no limit.

Agents

lua/agents.luanot a plugin

Coding agents run as plain jobstart(argv, { term = true }) terminals in a 33% bottom split, keyed by (agent, git root) so several stay alive side by side in one repository. The agent table and keymaps live in lua/plugins/agents.lua; adding one is a new entry plus a map(...) line.
